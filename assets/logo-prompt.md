# Minimal logo artwork

Created using the built-in image generation tool. Only the final minimal logo is included; discarded artwork is excluded.

## Prompt

Use case: ads-marketing. Create a minimal conceptual art thumbnail for the GitHub README of 'UniFi Loom', an open-source network MCP server. Wide landscape composition, warm off-white background. In the center, a tiny precise network motif: four small dark navy circles connected by extremely thin navy lines, with just one small cobalt blue node. A subtle crossing/weaving of two connecting lines suggests a loom. Vast calm negative space. Flat editorial graphic art, restrained, clean, tasteful. At the bottom center, only the exact text 'UniFi Loom' in small clean black sans-serif. No tagline, no gradients, no glows, no shadows, no 3D, no detailed hardware, no logos, no addresses, no UI panels, no extra decoration, no watermark. Visual simplicity is the main requirement. Crisp at thumbnail scale.
